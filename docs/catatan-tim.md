## Aturan kerja bersama
- Setiap anggota bekerja dari VPS control masing-masing, lalu mendorong ke GitHub.
- Jalankan `git pull --rebase` sebelum `git push`.
- Pesan commit memakai awalan konvensi: `feat:`, `fix:`, `docs:`, `chore:`.
- Jangan pernah commit berkas `.env`, kunci `*.key`, atau `*.pem`.
- Bila terjadi konflik, berhenti dan tanya dosen. Jangan paksa dengan `--force`.
